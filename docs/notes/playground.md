# demos/playground.html — interactive Deep Diffs playground

A single self-contained HTML file (diff-match-patch and an adapted copy of the deep-diff algorithm inlined; zero network requests, works from `file://`). It is the flagship demo of the technique.

**Features**: an editable left rail of revision cards (add / delete / reorder / inline edit with 250 ms debounced re-render) plus a bulk-paste mode with a configurable delimiter; a serif "manuscript" view (~65ch measure) of the deep diff; two heat modes — *Frequency* (amber highlighter deepening with overlap count, the classic deep diff) and *Recency* (cool slate → hot vermilion by each region's `lastTouched` revision); a bottom revision scrubber with arrow-key stepping ("after revision k of N"); hover tooltips ("added in v3 · last touched v6 · depth 2"); a mode-aware legend; a Copy-HTML export that puts a standalone styled snippet on the clipboard; and four crafted sample histories (negotiated contract clause, ten drafts of a poem, a flat-white edit war, a commit message being refined) whose edits deliberately nest inside earlier edits.

**Design decisions**: instead of literally nesting `<ins>` tags, the renderer cuts the final text at every marker boundary and emits one flat `<ins>` per covered segment carrying exact metadata (depth = overlapping markers, earliest birth revision, latest touch) — visually identical to nesting, but every hovered region reports precise numbers, and pathological partial overlaps can't produce malformed HTML. Marker snapshots are stored after every revision so scrubbing is instant. Heat ramps live in one JS table that generates both the page CSS and the export snippet, with alphas tuned per theme so text contrast holds in light and dark; the theme toggle sets `[data-theme]` on the root and wins over `prefers-color-scheme` in both directions. Painted newlines at segment edges are peeled out of the tags to avoid stray highlight slivers on blank lines. Fully responsive to ~720 px; no frameworks.
